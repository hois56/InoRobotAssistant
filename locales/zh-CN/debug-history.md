## communicationTester

### Ver 2.6 (2026.06.15)

- **【变更】** 根据标准化程序变更重新设计默认 HMI 画面。
- **【变更】** 将最新默认 HMI 内置到程序中，无需单独文件。
- **【改进】** 程序启动时自动应用内置默认 HMI。

### Ver 2.5 (2026.06.10)

- **【新增】** 为 HMI Code Block 添加脚本系统。
- **【添加】** 添加 If / ElseIf / Else / EndIf 条件语句。
- **【添加】** 添加逻辑、比较、算术运算和 Delay 命令。
- **【添加】** 脚本可读取或写入通信地址值。
- **【添加】** 添加自动完成、语法高亮和错误检查。
- **【添加】** 添加 Byte 与 BitField 数据类型。
- **【添加】** Word 数据可展开为 Bit、Byte 子行。
- **【改进】** 多重写入可处理各目标的数据类型。
- **【改进】** 提升与现有 HMI 文件的兼容性。

### Ver 2.4 (2026.04.26)

- **【变更】** 改为无需单独安装 .NET 运行时的自包含程序。
- **【变更】** 将程序和必要组件合并为一个可执行文件。
- **【修复】** 修正启动入口和部署路径设置。
- **【改进】** 提升运行与部署稳定性。

### Ver 2.3 (2026.04.13)

- **【添加】** 为 HMI Word Button 添加条件比较与执行。
- **【添加】** 添加单个按钮控制最多 10 个地址的多重写入。
- **【变更】** 条件目标与执行目标可分别设置。
- **【改进】** 改进 HMI 状态与触发提示。

### Ver 2.2 (2026.04.02)

- **【新增】** 在网站发布 Communication Tester。
- **【添加】** 添加 Modbus TCP 通信。

- **【添加】** 添加 TCP/IP Socket Client 与 Server 通信。
- **【添加】** 添加通信数据实时监控与控制。
- **【添加】** 添加可在 PC 上构建测试画面的 HMI Builder。

## labelGenerator

### Ver 2.1.0

- **【修复】** 修复同一地址存在 Bit、Byte、Word 标签时部分标签缺失或被覆盖的问题。
- **【变更】** 地址冲突时优先显示 Bit 标签，并在说明区域显示相关 Byte、Word 标签。
- **【添加】** 自动识别说明中的 Double Word、2 Word、DWORD、32-bit。
- **【修复】** Double Word 数据在 Excel 中按 32 位范围正确合并。
- **【变更】** 程序标题与可执行文件版本统一为 V2.1。

### Ver 2.0.0

- **【新增】** 将原先独立发布的标签格式合并到一个程序。
- **【添加】** 添加 20 字符 Word、20 字符 Byte、64 字符 Word、64 字符 Byte 格式。
- **【添加】** Excel 转 JSN 与 JSN 转 Excel 可分别选择格式。
- **【新增】** 添加 JSN 转 Excel 前检查、编辑标签名与说明的界面。
- **【添加】** 根据所选格式自动指定 Excel 文件名。
- **【变更】** 改进变量名规范化，在 20 字符格式中自动缩短长名称。
- **【变更】** 状态区域显示当前格式与已加载数据数。
- **【变更】** 默认格式改为 20 字符 Word。

### Ver 1.0.0

- **【新增】** 添加 Excel 标签数据转 JSN。
- **【新增】** 添加 JSN 转 Excel 标签工作簿。
- **【添加】** 支持 Input、Output 的 Bit、Byte、Word 标签。
- **【添加】** 支持 B、R、D 变量标签。
- **【添加】** 添加标签查看、排序、选择与编辑。
- **【添加】** 添加变量名规范化与变更预览。
- **【添加】** 支持 64 字符 Byte 与 20 字符 Word 格式。

- **【新增】** 添加 Tool、Work Object、Load 编号与 B/R/D 变量监控。
- **【新增】** 添加图表缩放、平移、通道分离和光标测量。
