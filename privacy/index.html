개인정보처리방침

시행일: 2026년 8월 12일
적용 대상: https://inovancerobot.com/ 및 그 하위 페이지

INOVANCE Robot Assistant(이하 “사이트”)는 방문자의 개인정보를 중요하게 생각합니다. 이 방침은 사이트가 어떤 정보를 어떤 목적으로 처리하는지 설명합니다.

사이트는 회원가입, 로그인, 결제 또는 문의 입력폼을 제공하지 않습니다. 방문자의 이름, 전화번호, 이메일 주소와 같은 정보를 사이트에서 직접 입력받아 저장하지 않습니다.

1. 운영자 및 문의

운영자: INOVANCE Robot Assistant
개인정보 관련 문의: inovancerobot@gmail.com

위 이메일 주소는 개인정보 및 사이트 운영 관련 문의를 위한 공식 연락처입니다. 문의 경로가 변경되면 이 페이지를 통해 최신 정보를 안내합니다.

2. 수집·처리하는 정보

가. Cloudflare Web Analytics

사이트 이용 현황과 성능을 파악하기 위해 Cloudflare Web Analytics를 사용합니다. 분석 대상에는 방문한 페이지 경로, 유입 페이지, 방문 시각, 브라우저·운영체제·기기 유형, 국가 단위의 위치 정보 및 페이지 성능 정보가 포함될 수 있습니다.

분석 기능은 쿠키, localStorage, sessionStorage 또는 IndexedDB를 사용하지 않도록 구성됩니다. Cloudflare는 분석 비콘 처리 과정에서 전달되는 IP 주소를 가까운 데이터센터에서 폐기하고 핵심 데이터베이스나 로그에 저장하지 않는다고 안내합니다.

나. 누적 방문자 수

홈페이지에 표시되는 기존 누적 방문자 수를 유지하기 위해 Cloudflare Worker와 SQLite 기반 Durable Object를 사용합니다. Worker는 IP 주소, 브라우저 정보(User-Agent), 언어 정보를 비밀키 기반 HMAC-SHA-256으로 변환하며 원본 값은 저장하지 않습니다. 방문자 조합 해시와 IP 기반 해시는 5분 동안 중복 방문 확인과 과도한 반복 요청 제한에 사용되고, 유효기간이 지난 행은 이후 요청 처리 중 삭제됩니다. 누적 방문자 수는 숫자 합계로만 저장됩니다. 전환 기간에는 기존 수치를 잃지 않도록 이전 Workers KV의 숫자 합계와 단기 중복 확인값을 일시적으로 대조합니다.

다. 외부 리소스 및 파일 다운로드

사이트의 화면·기능·파일 제공을 위해 Google Fonts, cdnjs, unpkg, esm.sh, GitHub 및 Cloudflare Worker 등의 외부 서비스가 사용될 수 있습니다. 브라우저가 해당 리소스를 요청할 때 IP 주소, 브라우저 정보, 요청 URL 등 일반적인 접속 정보가 해당 서비스로 전달될 수 있으며, 각 서비스의 개인정보처리방침과 이용약관이 적용됩니다.

3. 처리 목적

  • 페이지별 이용량과 방문 추이를 확인하여 사이트를 개선
  • 기존 누적 방문자 수를 표시하고 방문 추이를 확인
  • 페이지 로딩 성능과 오류 원인을 확인
  • 파일 다운로드 및 사이트 기능을 안정적으로 제공
  • 악성 요청, 자동화된 공격 및 서비스 남용을 방지

4. 보유 및 이용 기간

사이트 운영자가 회원 데이터나 원본 IP 주소를 직접 수집하여 보관하지는 않습니다. 누적 방문자 수는 숫자 합계로 보관됩니다. 중복 확인과 반복 요청 제한에 쓰이는 HMAC 해시는 5분 동안만 유효하며, 만료된 행은 이후 요청 처리 중 삭제됩니다. 전환 기간의 이전 Workers KV 값은 누적 수치 승계 확인이 끝날 때까지만 사용합니다. Cloudflare Web Analytics의 분석 데이터는 Cloudflare의 서비스 정책과 보관 설정에 따라 처리되며, 사이트 운영자는 분석 결과를 사이트 개선 목적에 한하여 사용합니다.

5. 제3자 제공 및 위탁

사이트는 방문자 정보를 판매하거나 광고 목적의 개인정보 목록으로 제공하지 않습니다. 다만 분석·호스팅·콘텐츠 전달·파일 제공에 필요한 범위에서 Cloudflare, GitHub 및 외부 CDN이 해당 서비스를 제공할 수 있습니다.

6. 방문자의 권리 및 문의

개인정보 처리에 관한 문의, 열람·정정·삭제·처리 제한 요청은 inovancerobot@gmail.com으로 보내주시기 바랍니다. 사이트에서 직접 식별 가능한 개인정보를 수집하지 않는 경우 요청을 처리할 수 있는 정보가 제한될 수 있습니다.

7. 방침의 변경

분석 도구, 외부 서비스 또는 관련 법령이 변경되면 이 페이지의 내용을 수정할 수 있습니다. 변경 시 시행일을 갱신하여 공개합니다.
