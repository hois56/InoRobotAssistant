# 3D 시뮬레이션 치수 측정 기능 추가 계획서

- 작성일: 2026-09-02
- 대상: `2_3DSimulation`
- 목표: 시뮬레이션 화면에서 스냅으로 두 점을 정확하게 선택해 치수를 표시하고, 입력한 거리값을 기준으로 3D 모델을 원하는 위치에 배치한다.

## 1. 요구사항 정리

1. 스냅 기능으로 3D 모델의 원하는 위치를 정확하게 선택한다.
2. 두 점 사이의 치수를 다음 중 하나로 선택해 표시한다.
   - 대각선 길이
   - X, Y, Z 축별 직각 치수
3. 화면 하단 제어 도크에 `치수` 버튼을 추가한다.
4. 3D 모델의 기준점을 스냅으로 선택하고, 시작점부터 목표점까지의 거리값을 입력해 해당 위치로 모델을 배치한다.

## 2. 현재 구조와 재사용 대상

현재 시뮬레이션에는 치수 측정에 활용할 기반 기능이 이미 구현되어 있다.

- `2_3DSimulation/index.html`
  - 하단 제어 도크 `#panel-launcher`가 `#stats-bar` 안에 존재한다.
  - 3D 화면 컨테이너는 `#canvas-container`이며, 스냅 마커를 이 컨테이너에 배치할 수 있다.
  - 현재 스냅 이동과 TCP 스냅에 필요한 스냅 유형 선택, 반경 설정, 상태 메시지 UI가 존재한다.
- `2_3DSimulation/main.js`
  - `state.snapCandidates`와 `findSimulationSnapAtPointer()`가 화면 좌표 근처의 스냅 후보를 찾는다.
  - `buildSimulationSnapCandidates()`가 `3_ToolSelector/snap-geometry.mjs`의 CAD 형상 분석을 재사용한다.
  - 끝점, 꼭짓점, 에지 중심점, 원/호 중심점, 사각형 중심점 등의 후보와 호버 마커 표시가 구현되어 있다.
  - `handleSimulationSnapClick()`에서 스냅 클릭과 다른 3D 화면 클릭의 충돌을 조정할 수 있다.
- `2_3DSimulation/style.css`
  - 하단 바, 패널, 스냅 마커, 반응형 모바일 제어 도크 스타일을 재사용할 수 있다.
- `tools/validate-3d-simulation-snaps.mjs`
  - 스냅 후보 생성, 대용량 모델, STEP 면 정보, HTML/CSS 계약을 검사하는 기존 검증 진입점이다.

현재 스냅 이동은 로봇을 이동시키기 위한 모드이며, 면을 먼저 선택한 뒤 해당 면의 스냅 후보를 선택하는 흐름이다. 치수 측정은 로봇을 이동시키지 않으므로 별도의 `measurement` 선택 컨텍스트를 추가하고, 측정 모드에서는 후보를 직접 호버·선택할 수 있도록 분리한다.

모델 배치는 측정과 별도의 `placement` 컨텍스트로 분리한다. 본 계획에서는 다음 방식으로 요구사항을 구현한다. 사용자가 이동할 3D 모델의 기준 스냅점 P1과 목적 방향을 정할 스냅점 P2를 선택하면 현재 P1→P2 거리를 자동으로 계산한다. 사용자가 목표 거리값을 입력하면 P1을 시작점으로 유지한 채 P1→P2 방향으로 입력 거리만큼 이동한 위치를 목표점으로 삼아 모델을 미리 배치하고, `적용`할 때 실제 모델 변환으로 확정한다.

## 3. 범위와 기본 정책

### 포함 범위

- 한 번에 하나의 측정 결과를 생성하고 다시 측정하거나 삭제할 수 있도록 한다.
- 두 점은 현재 시뮬레이션의 월드 좌표계 기준으로 저장한다.
- 측정 대상은 화면에 표시된 로봇 형상, Tool·암 로드, 장면 3D 모델 등 유효한 visible mesh로 한다.
- 그리드, 축 헬퍼, TCP 핸들, 선택 면 오버레이, 치수선 자체는 스냅 대상에서 제외한다.
- 기존 스냅 후보 생성기의 정확도·우선순위·대용량 모델 지연 생성 방식을 유지한다.
- 모델 이동, 로봇 자세 변경, 카메라 이동, 화면 크기 변경에도 치수 오버레이가 올바른 위치에 갱신되도록 한다.
- 선택한 업로드 3D 모델의 기준점을 스냅하고, P1→P2 방향과 입력한 목표 거리로 모델 이동 위치를 미리보기·적용한다.
- 배치 적용 시 기존 모델의 회전·크기는 유지하고 위치만 변경하며, 기존 Undo/Redo와 작업 저장 흐름에 연결한다.

### 제외 범위

- 각도, 반지름, 원주, 면적, 체적 측정
- 측정 결과의 CAD/PDF/CSV 내보내기
- 여러 측정 결과를 목록으로 관리하는 기능
- 사용자 좌표계 또는 Tool 좌표계로 변환한 치수
- 새 스냅 유형을 만드는 작업
- 거리값에 따른 자동 회전·자동 크기 변경
- 여러 모델을 한 번에 배치하거나 배치 결과를 별도 파일로 내보내는 기능

## 4. 사용자 흐름

1. 사용자가 하단의 `치수` 버튼을 클릭한다.
2. 치수 패널이 열리고 버튼은 활성 상태가 된다. 다른 스냅 이동·TCP 스냅·영점 스냅은 동시에 활성화하지 않는다.
3. 측정 패널에서 스냅 유형과 스냅 반경을 선택한다.
   - 기본값은 `자동 스냅`으로 한다.
   - 기존에 제공하는 끝점, 꼭짓점, 에지 중심점, 원/호 중심점, 사각형 중심점 선택을 제공한다.
4. 포인터를 모델 위로 이동하면 가장 가까운 유효 스냅 후보와 해당 월드 좌표를 표시한다.
5. 첫 번째 점을 클릭하면 `P1`을 고정하고, 두 번째 점 선택 안내로 전환한다.
6. 두 번째 점을 클릭하면 `P2`를 고정하고 치수선을 표시한다.
7. `대각선 길이` 또는 `직각 치수(X/Y/Z)` 라디오/세그먼트 선택을 변경하면 같은 두 점으로 표시 방식만 즉시 바꾼다.
8. `다시 측정`을 누르면 기존 결과를 제거하고 P1 선택 상태로 돌아간다. `치수 삭제` 또는 패널 종료 시 오버레이를 제거한다.
9. `Esc`는 측정 모드와 현재 측정 결과를 종료하는 단축 동작으로 사용한다.

### 모델 위치 배치 흐름

1. 치수 패널의 작업 모드를 `모델 배치`로 전환한다.
2. 모델 트리 또는 3D 화면에서 이동할 업로드 3D 모델을 선택한다. 로봇 본체 자체는 배치 대상에서 제외한다.
3. 선택한 모델의 기준점 P1을 스냅으로 선택한다. P1은 이동 후에도 같은 모델 로컬 위치를 가리키는 기준점이다.
4. 장면에서 방향과 목적을 정할 P2를 스냅으로 선택한다. P1과 P2가 같으면 방향을 계산할 수 없으므로 재선택을 요구한다.
5. 패널에 현재 거리 `|P2 - P1|`를 표시하고 목표 거리 입력값의 기본값으로 채운다.
6. 사용자가 목표 거리값을 입력하면 P1에서 P2 방향으로 입력 거리만큼 이동한 목표 위치와 X/Y/Z 변위를 미리보기한다.
7. `적용`을 누르면 모델 기준점이 목표 위치에 오도록 모델의 위치만 변경하고, 하나의 Undo/Redo 기록으로 저장한다. `취소`는 원래 위치로 복원한다.
8. P2를 그대로 목표점으로 사용하려면 자동으로 채워진 현재 거리값을 변경하지 않고 적용한다.

P1은 모델에 속한 스냅점이고 P2는 모델 또는 다른 장면 형상의 스냅점일 수 있다. 배치 모드에서 모델을 움직이는 동안 로봇 모션은 정지 상태여야 하며, 배치 미리보기 중 모델 삭제·숨김·외부 변환이 발생하면 미리보기를 폐기하고 다시 선택하도록 안내한다.

측정 중에는 유효한 스냅 후보를 클릭했을 때 모델 선택이나 다른 화면 클릭 이벤트가 실행되지 않도록 한다. 유효한 후보가 없으면 상태 메시지만 표시하고 측정 점은 확정하지 않는다.

## 5. UI 설계

### 하단 버튼

`2_3DSimulation/index.html`의 `#panel-launcher`에 다음 버튼을 추가한다.

- id: `btn-measurement`
- 아이콘: `fa-ruler-combined`
- 데스크톱 표시: `치수`
- 접근성: `title`, `aria-label`, `aria-pressed` 제공
- 활성 상태: 기존 `.viewer-control-dock button.active` 스타일과 동일한 시각 규칙 적용
- 모바일: 기존 하단 도크의 아이콘 전용 레이아웃을 따르되 title과 aria-label은 유지

### 치수 패널

기존 패널 스타일과 패널 스택을 재사용하는 `aside#measurement-panel`을 `#canvas-container`에 추가한다.

- 헤더: `DIMENSION MEASUREMENT`, 패널 숨김 버튼
- 현재 상태: `P1 선택`, `P2 선택`, `측정 완료`
- 스냅 설정: 유형 select, 반경 range, 현재 호버 좌표 readout
- 선택 점 readout: P1/P2의 X, Y, Z 좌표와 스냅 유형
- 표시 방식:
  - `대각선 길이`
  - `직각 치수(X/Y/Z)`
- 결과 영역:
  - 대각선 길이: `Distance = ... mm`
  - 직각 치수: `X = ... mm`, `Y = ... mm`, `Z = ... mm`
- 동작 버튼: `다시 측정`, `치수 삭제`

### 모델 배치 UI

치수 패널 상단에 `치수 측정`과 `모델 배치` 작업 모드를 제공한다. `모델 배치`를 선택하면 다음 항목을 표시한다.

- 이동 대상 모델명과 기준점 P1 좌표
- 방향/목표 스냅점 P2 좌표
- 현재 거리와 목표 거리 입력창: `목표 거리 (mm)`
- 입력 거리 기준의 목표 좌표와 `ΔX`, `ΔY`, `ΔZ` 미리보기
- `미리보기 갱신`, `적용`, `취소`, `다시 선택` 버튼

목표 거리 입력창은 0 이상의 유한한 값만 허용한다. 입력 중에는 모델의 실제 저장 상태를 바로 확정하지 않고 preview transform만 반영하며, `적용` 시점에만 기존 장면 snapshot을 이용해 Undo/Redo에 기록한다.

치수 패널은 기존 `PANEL_MINIMUM_SIZES`, `getPanelElement()`, `updatePanelLauncher()`, `togglePanelVisibility()` 흐름에 등록한다. 패널을 닫거나 다른 스냅 모드로 전환할 때 측정 상호작용을 안전하게 종료한다.

## 6. 데이터 및 계산 설계

### 상태 구조

`main.js`의 전역 `state`에 측정 전용 상태를 추가한다.

```js
measurement: {
    active: false,
    snapType: 'auto',
    snapRadiusPx: 16,
    points: [null, null],
    hover: null,
    displayMode: 'diagonal',
    result: null,
    lineGroup: null,
    labelElements: []
}
```

모델 배치 상태는 별도로 관리한다.

```js
placement: {
    active: false,
    model: null,
    sourcePoint: null,
    directionPoint: null,
    targetDistance: null,
    currentDistance: null,
    targetPoint: null,
    previewTranslation: null,
    historyBefore: null
}
```

각 측정 점은 단순히 화면 좌표를 저장하지 않고, 다음 정보를 함께 보관한다.

- `worldPoint`: 클릭 순간의 월드 좌표
- `mesh`: 선택된 mesh 참조
- `localPoint`: 모델 변환 갱신에 사용할 mesh 로컬 좌표
- `snapType`: 끝점, 꼭짓점, 에지 중심점 등
- `screenX`, `screenY`: 현재 카메라 기준 표시 위치

모델이 이동하거나 로봇 자세가 바뀌면 `localPoint`를 다시 월드 좌표로 변환해 결과를 갱신한다. 해당 mesh가 삭제되거나 숨겨지면 측정 결과를 stale 상태로 만들고 사용자에게 다시 측정하도록 안내한다. 측정 상태는 현재 작업 복구 데이터에 저장하지 않고, 페이지 재실행·작업 복구 시 초기화한다.

### 계산식

두 점을 `P1 = (x1, y1, z1)`, `P2 = (x2, y2, z2)`로 둔다.

```text
dx = x2 - x1
dy = y2 - y1
dz = z2 - z1

diagonal = sqrt(dx² + dy² + dz²)
orthogonalX = abs(dx)
orthogonalY = abs(dy)
orthogonalZ = abs(dz)
```

- 내부 계산은 `THREE.Vector3`와 배정밀도 숫자를 사용한다.
- 화면 표시는 기본 소수점 3자리 mm로 통일한다.
- 실제 계산값과 표시값을 분리해 반올림 오차가 다음 계산에 누적되지 않도록 한다.
- 두 점이 동일하거나 유효하지 않은 좌표이면 결과를 만들지 않고 오류 메시지를 표시한다.
- 직각 치수는 전역 시뮬레이션 X/Y/Z축 기준이며, 양수 방향/음수 방향은 결과값 옆의 `ΔX`, `ΔY`, `ΔZ` 또는 보조 정보로 확인할 수 있게 한다.

### 모델 배치 계산

모델 기준점 P1과 방향점 P2로부터 다음 값을 계산한다.

```text
direction = P2 - P1
currentDistance = |direction|
unitDirection = direction / currentDistance
targetPoint = P1 + unitDirection * targetDistance
translation = targetPoint - P1
```

- `targetDistance`의 기본값은 `currentDistance`로 한다.
- P1과 P2가 동일하면 `unitDirection`을 계산하지 않고 배치를 막는다.
- 적용 시 모델의 기준점이 `targetPoint`에 오도록 월드 이동량을 모델의 부모 좌표계로 변환해 `model.position`에 반영한다.
- Tool 또는 암 로드에 부착된 업로드 모델을 허용하는 경우에도 부착 부모와의 관계를 유지한 채 부모 로컬 좌표로 이동한다.
- 회전과 스케일은 변경하지 않는다.
- 배치 적용 전에는 `captureSceneSnapshot()`으로 원래 장면을 보관하고, 적용 시 `recordHistory('치수 기준 모델 배치', before, after)`와 `scheduleMotionProjectSave()`를 호출한다.

## 7. 3D 오버레이 설계

### 대각선 표시

- P1과 P2를 잇는 `THREE.Line`을 생성한다.
- 양 끝에는 기존 스냅 마커와 구분되는 고정 점 마커를 표시한다.
- 선 중간 또는 카메라에 가까운 안정적인 위치에 `Distance` 라벨을 표시한다.

### 직각 치수 표시

- P1에서 P2까지를 월드 X/Y/Z축 방향의 세 구간으로 분해한다.
- X, Y, Z 구간을 기존 축 색상인 빨강, 초록, 파랑 계열로 표시한다.
- 각 구간의 중간에 해당 축의 치수 라벨을 표시한다. 값이 0인 축도 결과 패널에는 표시하되, 화면 선은 생략하거나 최소 길이 보조선으로 처리한다.
- 선의 순서와 보조 꼭짓점은 `P1 → (x2,y1,z1) → (x2,y2,z1) → P2`처럼 고정된 규칙을 사용해 결과가 매번 같은 방식으로 보이게 한다.

### 렌더링 및 카메라 대응

- 치수선은 `state.scene` 안의 별도 그룹으로 관리하고, 씬 모델과 구분되는 render order와 재질을 사용한다.
- 텍스트는 CSS/HTML 오버레이로 관리해 확대·축소 시에도 읽을 수 있게 한다.
- 렌더 프레임 또는 카메라 change 시 월드 점을 화면에 재투영해 라벨 위치를 갱신한다.
- OrbitControls로 카메라를 이동하는 동안에는 새 스냅 후보 계산을 중단하고, 이동이 끝난 뒤 치수 라벨과 호버 마커를 한 번 갱신한다.
- 치수선이 모델에 가려져도 결과를 확인할 수 있도록 선과 측정 점의 depth 처리 정책을 별도로 정한다. 단, 모델 선택을 방해하지 않도록 pointer-events는 오버레이에서 차단한다.

## 8. `main.js` 구현 순서

1. `state.measurement`와 `el` 참조를 추가한다.
2. 치수 패널의 open/close, active 상태, 버튼 상태, `Esc` 처리를 추가한다.
3. 기존 스냅 로직에 `measurement` 컨텍스트를 추가한다.
   - `isSimulationSnapPicking()`에 측정 상태 포함
   - `getSimulationSnapScope()`에 측정 scope 추가
   - 측정 대상 mesh 조회 함수 분리
   - `findSimulationSnapAtPointer()`에서 측정용 스냅 타입·반경을 사용
   - 기존 `snapMoveMode`의 면 선택 선행 조건은 측정 모드에 적용하지 않음
4. 포인터 move/click 처리에 측정 분기를 추가한다.
   - 호버 후보 표시
   - P1 저장
   - P2 저장 및 계산
   - 다른 화면 선택 이벤트와 전파 충돌 방지
5. `placement` 컨텍스트와 모델 배치 이벤트를 추가한다.
   - 선택 모델 및 모델 기준 스냅점 P1 지정
   - 방향/목표 스냅점 P2 지정
   - 목표 거리 입력과 실시간 preview transform
   - 적용·취소·다시 선택·유효성 검사
6. `calculateMeasurementResult(p1, p2)`와 표시 방식별 결과 렌더러를 추가한다.
7. `calculatePlacementTarget(p1, p2, targetDistance)`와 부모 좌표계 변환을 추가한다.
8. 치수선, 직각 보조선, 점 마커, HTML 라벨, 모델 배치 미리보기의 생성·갱신·삭제 수명주기를 구현한다.
9. 모델 삭제, 모델 숨김, 초기화, 로봇 모션 시작, 작업 복구 시 stale 측정·배치 미리보기를 처리한다.
10. `requestRender()`, `onResize()`, 카메라 change/end 이벤트와 연동해 오버레이와 배치 미리보기를 갱신한다.
11. 다른 스냅 모드, 모델 선택, TransformControls와의 상호 배타성 및 패널 스택 상태를 점검한다.

## 10. 검증 계획

### 자동 검증

- 순수 계산 검증을 추가한다.
  - 3-4-12 좌표의 대각선이 13 mm인지 확인
  - 각 축 성분이 3, 4, 12 mm인지 확인
  - 음수 좌표, 같은 점, 한 축만 다른 경우 확인
  - 유한하지 않은 입력 거부 확인
- 모델 배치 계산 검증을 추가한다.
  - P1=(0,0,0), P2=(3,4,0), 목표 거리 10 mm일 때 목표점이 (6,8,0)인지 확인
  - 목표 거리를 현재 거리로 두었을 때 P2와 일치하는지 확인
  - P1=P2인 경우와 음수·무한·문자열 거리 입력을 거부하는지 확인
  - 부모 좌표계가 회전·이동된 모델에서도 월드 목표점에 맞게 이동량이 변환되는지 확인
- 스냅 컨텍스트 검증을 추가한다.
  - 측정 모드에서 측정 대상 mesh만 후보가 되는지 확인
  - grid/axes/overlay가 후보로 들어가지 않는지 확인
  - 자동 스냅과 특정 스냅 유형 선택이 각각 동작하는지 확인
  - 기존 스냅 이동·TCP 스냅 동작이 변하지 않는지 확인
- HTML/CSS 계약 검증을 추가한다.
  - `btn-measurement`, `measurement-panel`, 표시 방식 선택자 존재 확인
  - 모바일 하단 버튼 스타일과 접근성 속성 확인
- 기존 검증과 다국어 검증을 실행한다.

```powershell
node tools\validate-3d-simulation-snaps.mjs
node tools\validate-localized-site.cjs
```

다국어 원본을 변경한 경우에는 다음 순서로 생성 파일을 갱신한 뒤 검증한다.

```powershell
node tools\build-localized-site.cjs
node tools\validate-localized-site.cjs
```

### 수동 UI 검증

- 빈 시뮬레이션에서 `치수` 버튼이 비활성화 또는 안내 상태로 정상 표시되는지 확인한다.
- 로봇과 STEP/STL/FBX 모델에서 끝점, 꼭짓점, 에지 중심점, 원/사각형 중심점을 각각 선택한다.
- P1과 P2를 선택한 뒤 대각선 길이와 X/Y/Z 직각 치수를 번갈아 변경한다.
- `모델 배치` 모드에서 업로드 3D 모델을 선택하고 P1/P2를 스냅한 뒤 목표 거리값을 변경한다.
- 거리 입력에 따른 모델 위치 미리보기, 적용, 취소, Undo/Redo가 각각 정상 동작하는지 확인한다.
- 목표 거리값을 현재 거리 그대로 적용했을 때 모델 기준점이 P2에 정확히 도달하는지 확인한다.
- 카메라 회전·이동·확대, 브라우저 resize 후 선과 라벨의 위치가 점에 맞는지 확인한다.
- 모델 위치 변경 및 로봇 JOG 후 측정값이 갱신되는지, 모델 삭제·숨김 후 stale 안내가 나오는지 확인한다.
- 치수 측정 중 모델 선택, 스냅 이동, TCP 스냅, 영점 변경과의 이벤트 충돌이 없는지 확인한다.
- 한국어·영어·중국어·베트남어에서 버튼, 패널, 상태 메시지, 결과 라벨이 누락되거나 혼합되지 않는지 확인한다.
- 대용량 STEP/STP 모델에서 포인터 이동과 카메라 조작이 허용 가능한 응답성을 유지하는지 확인한다.
