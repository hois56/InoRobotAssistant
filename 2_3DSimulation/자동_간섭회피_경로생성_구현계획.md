# 3D 시뮬레이션 자동 간섭 회피 경로 생성 구현 계획

## 1. 문서 목적

이 문서는 3D 시뮬레이션에서 사용자가 프로그램에 저장한 시작·목표 이동 포인트를 지정하면, 로봇과 생성된 3D 모델링 사이의 간섭을 피하는 이동 경로를 자동으로 계산하고 두 이동 명령 사이에 모션 포인트로 등록하는 기능의 구현 계획을 정의합니다.

현재 프로젝트에는 3D 메시 충돌 검사, 로봇 역기구학(IK), 모션 포인트 저장 및 `P.pts` 내보내기 기능이 이미 있으므로, 기존 기능을 연결하는 경로 계획 계층을 추가하는 방식으로 구현합니다.

## 2. 목표 및 완료 조건

### 목표

- 프로그램의 시작 이동 포인트에서 목표 이동 포인트까지 자동 경로를 생성합니다.
- 타겟 위치가 로봇의 작업 범위와 관절 제한 안에 있는지 확인합니다.
- 이동 중 로봇 링크, Tool, Arm Load 및 충돌 감지 대상 3D 모델과의 간섭을 검사합니다.
- 먼저 목표까지의 직접 `MOVJ` 구간을 검사하고, 충돌이 없으면 `MOVJ`를 사용합니다.
- `MOVJ` 구간에 충돌이 있으면 TCP 선형 보간 경로와 안전 높이 Cartesian 우회 경로를 검사합니다.
- 생성된 전체 경로의 관절 보간이 안전하면 `MOVJ`, 관절 보간에서 충돌이 발생하고 Cartesian 보간이 안전하면 `MOVL`로 자동 결정합니다.
- 자동으로 결정한 모션 종류를 목표 이동 명령에도 반영해 미리보기와 실제 실행 궤적을 일치시킵니다.
- 사용자가 확인하기 전에는 자동으로 로봇을 실행하지 않습니다.

### 완료 조건

- 목표 자세의 IK 계산이 성공해야 합니다.
- 시작 자세와 목표 자세가 충돌 상태가 아니어야 합니다.
- 각 경로 노드와 노드 사이의 중간 자세가 충돌하지 않아야 합니다.
- 생성 포인트가 기존 포인트와 같은 형식으로 저장되어야 합니다.
- 경로 생성 실패 또는 취소 시 기존 로봇 자세와 프로그램이 변경되지 않아야 합니다.
- 생성된 포인트가 기존 모션 실행, 저장, 복구 및 `P.pts` 내보내기 기능과 호환되어야 합니다.

## 3. 현재 프로젝트에서 재사용할 기능

### 충돌 검사

`2_3DSimulation/collision-system.mjs`의 `MeshCollisionSystem`을 사용합니다.

- BVH 기반 삼각형 정밀 충돌 검사
- 여러 CAD 하위 메시 처리
- `collisionGeometry` 충돌 프록시 처리
- Tool과 로봇 링크의 부착 구조 인식
- Arm Load와 로봇 링크의 간섭 검사
- 충돌 대상 모델의 표시 여부 및 `collisionDisabled` 상태 반영

경로 계산 중에는 일반 화면의 충돌 메시지를 반복 갱신하지 않고, 별도의 경로 평가기를 통해 충돌 여부만 조회합니다.

### 로봇 자세 및 IK

`2_3DSimulation/main.js`의 기존 함수를 사용합니다.

- `getCurrentTcpPoseBase()`
- `solveRobotIK()`
- `solveScaraIK()`
- `setJointAngle()`
- `restoreRobotJointAngles()`
- `getCollisionModels()`

자동 경로의 시작 위치와 목표 위치는 프로그램에 저장된 `MOVJ` 또는 `MOVL` 이동 포인트에서 선택합니다. 각 포인트의 관절값과 TCP 위치·자세를 경로 계산의 양 끝점으로 사용하므로 좌표와 자세를 별도로 입력하지 않습니다.

### 모션 포인트

`captureRobotMotionStep()`을 이용해 기존 수동 포인트와 동일한 형식으로 자동 포인트를 생성합니다.

자동 생성 포인트에는 다음 정보를 포함합니다.

- 포인트 번호
- `MOVJ` 또는 `MOVL` 모션 종류
- 속도
- 관절값
- TCP 위치
- TCP 방향 쿼터니언
- Arm Parameter
- 외부축 값
- 포인트 라벨

포인트 번호는 기존 `nextAvailablePointIndex()`를 사용해 중복을 방지합니다.

## 4. 사용자 동작 흐름

프로그램 패널에 `자동 경로 생성` 버튼을 추가합니다.

```text
자동 경로 생성 버튼
    ↓
프로그램의 시작 P와 목표 P 선택
    ↓
경로 생성 시작
    ↓
3D 화면에 경로 미리보기
    ↓
사용자가 경로 적용
    ↓
두 이동 명령 사이에 우회 포인트 등록
```

경로 계산 중에는 다음 상태를 표시합니다.

- 목표 위치 분석 중
- 목표 IK 계산 중
- 직선 경로 검사 중
- 우회 경로 탐색 중
- 경로 최적화 중
- 최종 간섭 검사 중

경로가 생성되면 다음 동작을 제공합니다.

- 경로 적용
- 경로 취소
- 경로 다시 계산
- 선택한 두 이동 명령 사이에 생성 포인트 등록

기본 동작은 `경로만 생성하고 자동 실행하지 않음`으로 합니다.

## 5. 입력 UI 계획

### 시작·목표 포인트

- 시작 위치: 프로그램의 이동 포인트(`P[n]`) 선택
- 목표 위치: 프로그램의 이동 포인트(`P[n]`) 선택
- 시작 포인트는 목표 포인트보다 프로그램 앞에 있어야 합니다.
- 두 포인트는 서로 달라야 합니다.
- 포인트에 저장된 TCP 위치·자세와 관절값을 그대로 사용합니다.
- `현재 TCP 자세 유지`는 기본으로 활성화하며, 활성화된 경우 우회 구간의 TCP 방향을 시작 포인트 방향으로 고정합니다.

### 경로 설정

사용자가 설정하는 항목은 다음과 같습니다. `MOVJ`·`MOVL`은 충돌 검사 결과에 따라 프로그램이 자동으로 결정합니다.

- 현재 TCP 자세 유지 여부
- 이동 속도
- 최대 경로 포인트 수
- 최대 계산 시간

생성된 우회 포인트는 목표 이동 명령 바로 앞에 삽입해 시작·목표 이동 명령 사이에 배치합니다.

정확한 3D 메시 안전거리 계산은 별도의 확장 기능으로 분리합니다. 1차 구현은 실제 메시 간섭 여부와 충분히 촘촘한 경로 샘플링을 기준으로 합니다.

## 6. 경로 생성 알고리즘

### 6.1 사전 조건 검사

경로 생성 전에 다음 조건을 확인합니다.

- 활성 로봇이 선택되어 있는지
- 로봇이 관절 및 TCP 프레임을 제공하는지
- 시작·목표 이동 포인트가 선택되어 있는지
- 시작 포인트가 목표 포인트보다 프로그램 앞에 있는지
- 현재 모션이 실행 중이 아닌지
- 충돌 검사 시스템이 준비되었는지
- 선택한 목표 포인트가 로봇의 작업 범위 안에 있는지
- 목표점 자체가 모델 내부에 있지 않은지

조건을 충족하지 못하면 기존 프로그램과 로봇 자세를 변경하지 않고 실패 사유만 표시합니다.

### 6.2 시작 자세 및 목표 자세 저장

경로 계산 전에 다음 상태를 복사합니다.

- 경로 계산 전 실제 로봇 관절값
- 선택한 시작 포인트의 관절값·TCP 위치·TCP 방향
- 선택한 목표 포인트의 관절값·TCP 위치·TCP 방향
- 현재 활성 프로그램 로봇
- 외부축 값
- 기존 충돌 표시 상태

경로 계산 중 임시로 관절값을 변경하더라도 계산이 끝나면 반드시 원래 상태로 복구합니다.

### 6.3 목표 IK 계산

선택한 목표 이동 포인트의 TCP 위치와 자세에 대해 `solveRobotIK()`을 실행합니다.

검사 항목은 다음과 같습니다.

- 작업 범위 초과 여부
- 관절 최소·최대 범위
- 로봇 종류별 회전축 제한
- SCARA의 기울기 제한
- 목표 자세의 정밀도
- 순기구학으로 재계산한 실제 TCP와 목표 TCP의 오차

목표점이 충돌 상태이거나 IK 계산에 실패하면 경로 탐색을 시작하지 않습니다.

### 6.4 직선 경로 우선 검사

먼저 선택한 시작 포인트의 관절값에서 목표 포인트의 관절값까지 직접 `MOVJ` 구간을 촘촘하게 검사합니다. 충돌이 없으면 추가 포인트 없이 `MOVJ`를 사용합니다. `MOVJ` 구간에 충돌이 있을 때만 선택한 시작 TCP에서 목표 위치까지의 직선 Cartesian 경로를 검사합니다. `현재 TCP 자세 유지`가 활성화된 경우 Cartesian 후보 경로에서는 시작 포인트의 TCP 방향을 유지합니다.

각 샘플 위치에 대해 다음을 확인합니다.

- TCP 위치 선형 보간
- TCP 방향 SLERP 보간
- 해당 TCP 자세의 IK
- 모든 관절 제한
- 로봇 및 부착 모델과 3D 모델의 충돌 여부

기존 `solveMovlSamples()`의 위치·회전 샘플링 구조를 확장해 충돌 평가를 포함합니다.

직접 `MOVJ` 또는 중간 포인트를 포함한 `MOVJ` 경로가 안전하면 `MOVJ`로 결정합니다. 관절 보간에서 충돌이 발생하지만 Cartesian 경로가 안전하면 `MOVL`로 결정합니다. 우회가 필요한 경우에만 시작·목표 포인트 사이의 중간 경로 노드를 새 모션 포인트로 생성합니다.

### 6.5 우회 경로 탐색

직접 `MOVJ`와 직선 Cartesian 경로가 충돌하면 시작·목표 TCP 위치를 잇는 안전 높이 Cartesian 경로를 낮은 높이부터 탐색합니다. 이 경로의 관절 보간 전체가 안전하면 `MOVJ`로 사용하고, 관절 보간에서 충돌하면 Cartesian 보간을 사용하는 `MOVL`로 사용합니다. Cartesian 경로가 실패하면 `RRT-Connect` 양방향 알고리즘으로 충돌이 없는 관절 공간 경로를 탐색하고 `MOVJ`로 사용합니다.

```text
시작 관절 자세 트리  ↔  목표 관절 자세 트리
```

각 노드는 다음 정보를 가집니다.

- 관절값 배열
- 부모 노드
- 경로 비용
- TCP 위치
- 충돌 검사 결과

#### 관절 공간 샘플링

- 회전 관절은 각 관절의 최소각과 최대각 사이에서 샘플링합니다.
- 직동 관절은 최소거리와 최대거리 사이에서 샘플링합니다.
- 일정 확률로 목표 자세를 직접 샘플링해 탐색 속도를 높입니다.
- 관절 범위를 정규화해 관절별 단위가 다른 문제를 줄입니다.

#### 노드 검사

새 노드를 연결하기 전에 다음을 확인합니다.

- 모든 관절이 제한 범위 안인지
- 관절 변화량이 허용 범위 안인지
- 해당 자세의 TCP가 유효한지
- 로봇 링크와 외부 3D 모델이 겹치지 않는지
- 부착 Tool과 Arm Load가 모델과 겹치지 않는지
- 다른 충돌 대상 로봇과 겹치지 않는지

#### 간선 검사

노드 A와 B의 양 끝점만 검사하지 않고, 관절 보간을 통해 중간 자세도 검사합니다.

```text
A ── 샘플 1 ── 샘플 2 ── 샘플 3 ── B
```

기본 샘플 간격은 다음 범위에서 시작합니다.

- 회전 관절: 약 2~3도
- 직동 관절: 약 5~8mm

변화량이 큰 구간은 자동으로 샘플 수를 늘립니다.

## 7. 충돌 평가기 설계

경로 계산용 충돌 평가기는 화면용 충돌 감지와 분리합니다.

```text
PathCollisionEvaluator
 ├─ 후보 관절값 임시 적용
 ├─ 로봇 MatrixWorld 갱신
 ├─ Tool·Arm Load 위치 갱신
 ├─ MeshCollisionSystem.checkAll() 호출
 ├─ 충돌 여부 반환
 └─ 원래 관절값 복구
```

평가기는 다음 원칙을 지킵니다.

- 경로 계산 중 일반 충돌 상태창을 갱신하지 않습니다.
- 계산 완료 후 최종 결과만 화면에 반영합니다.
- 계산 시작 전에 `MeshCollisionSystem.prepare()`로 BVH를 준비합니다.
- 로봇과 부착 모델을 변경된 루트로 전달해 오래된 충돌 캐시를 재사용하지 않도록 합니다.
- 경로 계산이 실패하거나 취소되면 원래 관절값을 복구합니다.

기본 충돌 대상은 다음과 같습니다.

- 활성 로봇 링크
- 활성 로봇의 Tool
- 활성 로봇의 Arm Load
- 다른 로봇
- 충돌 감지가 활성화된 외부 3D 모델

기존 충돌 시스템의 자기충돌 검사 범위는 경로 생성 기능과 별도로 확인하고, 필요한 경우 2차 기능으로 확장합니다.

## 8. 경로 후처리

RRT가 생성한 경로는 불필요하게 많은 노드를 포함할 수 있으므로 후처리합니다.

### 불필요한 노드 제거

중간 노드를 제거해도 직접 연결 구간이 안전하면 해당 노드를 삭제합니다.

```text
A → B → C
```

를 다음처럼 줄일 수 있습니다.

```text
A → C
```

### 경로 단순화

현재 노드에서 먼 후속 노드까지 직접 연결을 시도합니다. 직접 연결 구간이 충돌하지 않으면 중간 노드를 제거합니다.

### 관절 변화량 제한

한 포인트 사이의 관절 변화량이 너무 크면 구간을 추가 포인트로 나눕니다.

### 최종 검증

후처리된 경로 전체를 시작부터 목표까지 다시 검사합니다. 최종 검증을 통과한 경로만 포인트로 등록합니다.

## 9. MOVJ 및 MOVL 자동 결정

사용자는 모션 종류를 선택하지 않습니다. 경로 생성기는 후보 경로를 충돌 검사하고, 같은 후보 경로를 `MOVJ`로 실행해도 안전한지 확인한 뒤 실행 모션을 결정합니다.

```text
직접 MOVJ 검사
    ├─ 안전함 → MOVJ
    └─ 충돌 → Cartesian 직선·안전 높이 경로 검사
                   ├─ 관절 보간도 안전함 → MOVJ
                   └─ 관절 보간 충돌, Cartesian 보간 안전 → MOVL
```

`MOVL`로 결정된 구간은 TCP 위치를 선형 보간하고 TCP 방향을 SLERP 또는 고정 방향으로 보간하며, 실행 중에도 동일한 방식으로 IK를 계산합니다. 목표 이동 명령으로 들어가는 마지막 구간도 실제 목표 TCP 자세까지 별도로 검사합니다.

`현재 TCP 자세 유지`는 Cartesian 후보 경로의 TCP 방향 조건입니다. `MOVJ`는 관절 보간 명령이므로 TCP 자세가 이동 중 변할 수 있으며, 해당 경로가 충돌 없이 안전하면 프로그램은 `MOVJ`를 우선 사용합니다. Cartesian 보간이 필요한 경우에는 체크된 TCP 자세 조건을 적용하고 `MOVL`로 등록합니다.

단, `MOVL` 구간은 다음을 모두 검사해야 합니다.

- TCP 위치의 선형 보간
- TCP 방향의 SLERP 보간
- 모든 중간 위치의 IK
- 모든 중간 자세의 충돌 여부

`solveMovlSamples()`는 IK와 충돌 평가 콜백을 함께 수행하며, 목표 포인트의 저장 관절값과 IK 결과가 다른 경우 최종 접근 경로를 실패 처리합니다.

## 10. 포인트 등록 방식

최종 경로가 확정되면 각 경로 노드의 관절값을 임시로 적용하고 `captureRobotMotionStep()`으로 포인트를 만듭니다.

처리 순서는 다음과 같습니다.

1. 경로 노드의 관절값을 로봇에 적용합니다.
2. MatrixWorld를 갱신합니다.
3. 현재 TCP 위치와 자세를 계산합니다.
4. 기존 포인트 생성 함수를 사용해 모션 포인트를 만듭니다.
5. 다음 경로 노드에 대해 같은 과정을 반복합니다.
6. 원래 로봇 자세를 복구합니다.
7. 충돌 검사로 결정된 `MOVJ` 또는 `MOVL`을 목표 이동 명령에 반영합니다.
8. 목표 이동 명령 바로 앞에 포인트를 삽입합니다.
9. 전체 삽입과 목표 모션 변경을 하나의 Undo 작업으로 기록합니다.

자동 생성 포인트의 라벨은 기존 라벨 규칙을 준수합니다. 포인트 번호는 기존 프로그램에서 사용하지 않는 번호를 자동으로 선택합니다.

## 11. 화면 경로 미리보기

경로 생성 완료 후 3D 화면에 다음을 표시합니다.

- 시작점
- 목표점
- 경로 선
- 각 경로 포인트 마커
- 경로 방향 표시
- 충돌로 실패한 경우 실패 구간 또는 충돌 모델

경로를 적용하지 않고 취소하면 미리보기 선과 마커를 제거합니다.

## 12. 성능 및 안정성 대책

CAD 모델은 삼각형 수가 많을 수 있으므로 다음 대책을 적용합니다.

- BVH 사전 준비
- AABB broad phase 우선 검사
- 충돌 발견 즉시 후보 경로 중단
- 경로 탐색 반복 횟수 제한
- 최대 계산 시간 제한
- `requestAnimationFrame()` 단위로 탐색 작업 분할
- 계산 취소 버튼 제공
- 결정론적 난수 시드 사용
- 고해상도 렌더 메시와 충돌 프록시 메시 분리

초기 권장 제한값은 다음과 같습니다.

- 최대 탐색 시간: 5~10초
- 최대 노드 수: 5,000~20,000개
- 목표 자세 샘플링 확률: 10~20%
- 최대 경로 포인트 수: 30~50개

경로 계산 중 다른 로봇이 움직이거나 장애물 모델의 위치가 변경되면 계산을 무효화하고 다시 계산하도록 합니다.
