# 설비 동작 시뮬레이션 사용법

## 시작하기

1. **모델 트리에서 움직일 모델 또는 부품을 우클릭 → 동작 설정**을 연다. 선택한 부품이 가동부로 자동 지정된다.
2. 동작 종류를 고르고 필요한 항목을 설정한다. 진공은 흡착 패드와 Output만 지정하고, 오브젝트는 대상만 등록한다.
3. 함께 움직일 부품은 목록에서 체크한다. **모델 트리에서 추가**를 누른 뒤 트리 항목을 클릭해서 선택할 수도 있다. 여러 부품을 고른 뒤 **선택 완료**를 누르면 일반 모델 선택으로 돌아간다.
4. 같은 화면의 **IO 연결**에서 작동 상태(ON/OFF)와 Output 주소를 입력하고 **동작 저장**을 누른다. IO가 필요 없으면 주소를 비워둔다.
5. 하단 **IO 테스트**에서 연결한 신호를 켜면 동작한다. **프로그램 Run 없이도** 운전할 수 있고, 이미 켜져 있는 신호에 연결해도 바로 반응한다.

저장한 동작은 트리에서 다시 우클릭해서 편집할 수 있다. 완료 Input은 **IO 연결**에서, 본체·탑재물·로봇 연결·파지 영역·필름 세부 항목은 **추가 옵션**에서 지정한다. 화면의 시험 버튼으로 직접 전진·후진을 확인할 수 있다.

신호를 지정 상태로 유지하면 해당 명령을 수행한다. 이동 명령이 없으면 현재 위치를 유지하며, 양방향 명령이 동시에 활성화되면 오류로 정지한다. **IO 제어 재개**는 수동 시험 명령을 해제하고 IO 운전으로 돌아간다. 작업공간에서 복구한 설비는 정지 상태이며 IO 제어 재개 또는 새 IO 신호로 운전한다.

설비 설정과 IO 기능 매핑 창을 열어도 배경을 어둡게 하거나 다른 창을 잠그지 않는다. 설비 설정 창의 제목을 드래그해서 위치를 옮기고 오른쪽 아래 모서리로 크기를 조절할 수 있다.

## 실제 모델 설정

- 고정부와 가동부는 서로 다른 모델 또는 분리된 CAD 부품으로 선택한다. 한 개 메시 안의 일부 형상을 자동으로 분리하지 않는다.
- 가동부·탑재물 목록은 **체크박스**로 여러 부품을 선택하거나 해제한다. 선택한 부품은 하나의 설비로 함께 움직인다. 그리퍼는 첫 번째와 두 번째 손가락 그룹에 각각 여러 부품을 지정한다. 변형할 필름은 설비마다 하나씩 지정한다.
- 상위 모델과 그 하위 부품을 같은 그룹에 함께 지정해도 이동량이 중복 적용되지 않는다. 이미 이동한 설비에 부품을 추가하면 기존 부품의 기준 위치와 현재 이동량을 유지하며 추가 부품도 현재 배치에서 합류한다.
- 이동축, 회전 중심, 파지 영역 중심은 본체 프레임 기준이다. 고정부를 생략하면 등록 당시 가동부 프레임을 기준으로 한다.
- 초기 배치가 복귀 위치다. 실행 중 현재 위치가 아닌 등록 시 기준 위치로부터 행정을 계산한다.
- 직선 이동은 mm·mm/s, 회전은 deg·deg/s다. 범위를 초과하는 E축 값과 삭제된 부품은 오류로 표시한다.
- 가동부 또는 탑재물을 여러 설비가 동시에 제어하거나 같은 센서 주소를 여러 설비에 지정할 수 없다.
- 설비 센서에 연결한 In은 설비 위치와 파지 상태에 따라 갱신된다. IO 테스트에서 수동 덮어쓰기를 제한한다.

## 설비별 설정

### 오브젝트

제품 모델 또는 하위 부품을 선택하고 동작 종류를 **오브젝트**로 저장한다. 이동 거리·속도나 IO 연결은 없다. 그리퍼·진공·컨베이어는 오브젝트로 등록한 항목만 잡거나 이송한다. 여러 항목을 한 번에 등록할 수 있고 등록은 프로젝트에 저장된다.

### 진공

흡착 패드 모델 또는 부품을 선택하고 동작 종류를 **진공**으로 저장한다. **흡착 Output 번호**만 연결하면 된다. Output이 켜질 때 패드와 실제로 닿은 등록 오브젝트를 흡착하고, 패드가 움직이거나 회전하면 붙은 물체도 따라간다. 로봇 Tool에 설치한 패드도 해당 Tool을 따라 움직인다. 신호가 꺼지면 현재 위치에서 물체를 놓는다. 설정 창의 **흡착 / 해제** 버튼으로도 확인할 수 있다.

### 컨베이어

벨트 모델 또는 조립 모델의 벨트 부품 하나를 지정하고 방향·속도를 설정한다. 높은 가이드나 프레임이 있는 조립 모델은 실제 벨트 부품을 선택한다. 벨트 상면의 오브젝트로 등록된 물체가 설정한 방향으로 이동한다. IO 번호 없이도 저장하고 **이송 / 정지** 버튼으로 확인할 수 있다. IO 운전은 이송 IO 번호를 연결한다.

### 실린더

본체와 로드를 선택하고 축·행정·전진/복귀 속도를 설정한다. 전진과 후진은 각각 별도 매핑으로 연결한다. 복귀·전진 완료 센서는 끝 위치에 도달하면 ON이며 중간 위치에서는 양쪽 모두 OFF다.

### 외부 축

직선 또는 회전 종류를 선택하고 가동 테이블과 탑재물을 지정한다. 독립 IO 명령 또는 로봇 E축을 연결할 수 있다. 로봇을 탑재물로 지정하면 테이블과 로봇이 함께 이동한다. E축 연결 시 같은 값으로 로봇이 다시 이동하지 않도록 처리한다. 기존 모듈에 연결하지 않은 E축 동작은 유지한다.

### 그리퍼

본체와 서로 다른 손가락 2개를 지정한다. 첫 손가락은 지정 축의 반대 방향, 두 번째 손가락은 지정 축 방향으로 닫힌다. 열림 폭은 초기 배치의 실제 안쪽 간격과 일치시킨다.

파지 영역 중심·길이·높이를 공작물 위치에 맞춘다. 영역 안에서 오브젝트로 등록되고 크기가 맞는 공작물에 접촉하면 닫힘을 멈추고 파지한다. 빈 닫힘과 파지 감지를 구분한다. 열림 명령으로 충분히 열린 후 해제하며 물체의 World 위치를 유지한다. 로봇을 연결하면 본체와 손가락, 파지 물체가 로봇 툴 프레임을 따라간다.

### 필름 박리

제품과 별도 필름 모델을 지정하고 길이·폭·굽힘 강성·감쇠를 설정한다. **같은 필름의 손잡이 부품**에 가장자리의 손잡이를 모두 추가하고, **필름을 잡는 그리퍼 / 파지 모델**에서 그리퍼 본체나 손가락 부품을 지정한다. 손잡이가 여러 개여도 하나의 필름이며, 가까운 손잡이 하나를 잡으면 다른 손잡이도 같은 필름의 위치와 굽힘을 따라간다.

등록된 그리퍼는 손잡이 근처에서 닫혀야 파지한다. **박리** 버튼이나 Output으로 동작을 활성화한 뒤 로봇·그리퍼를 제품 안쪽 방향으로 당기며 들어 올리면, 실제 파지점 위치에 따라 필름이 벗겨진다. 그리퍼가 멈추면 박리량도 유지되며, 손잡이의 파지 폭에서 손가락이 멈추고 그리퍼 파지 감지 Input을 켠다. 완전히 벗긴 후 그리퍼를 열거나 **필름 놓기**를 누르면 필름을 놓는다.

손잡이 부품이 따로 나뉘어 있지 않으면 **손잡이가 있는 변**, **손잡이 위치 (0~100%)**, **손잡이 파지 폭**으로 잡는 구간을 지정할 수 있다. 파지 모델과 로봇을 모두 생략한 경우에만 박리 속도로 필름을 곡선으로 들어 올리는 시험 경로를 사용한다. 초기화한 필름은 평평한 상태에서 시작한다.

붙어 있는 구간은 제품 평면에 유지하고, 별도 파지점으로 당기거나 놓은 필름에는 길이·굽힘·중력·감쇠 제약을 적용한다. 자유 길이보다 먼 파지점은 오류로 표시한다. 전체 길이를 완전히 박리하기 전에는 필름을 놓을 수 없으며, 완료 후에도 파지 상태를 유지하다가 **필름 놓기** 명령으로 놓는다. 후진으로 다시 붙이지 않으며 처음부터 다시 시험하려면 초기화를 사용한다.

초기 버전은 직사각형 필름과 평면 제품·바닥 접촉을 대상으로 한다. 접착력·박리력 해석, 복잡한 제품 표면, 필름 자체 충돌과 미세 주름은 구현 범위에 포함하지 않는다.

## 프로그램 패널과 OLP

프로그램 패널의 **IO Out** 버튼은 출력 명령을, **IO Wait** 버튼은 입력 대기 명령을 추가한다. 각 행에서 주소와 ON/OFF를 설정하고 다른 이동 명령 사이에 배치한다. 입력 대기는 지정 상태가 될 때까지 다음 명령으로 넘어가지 않는다.

예를 들어 실린더를 전진 Out[600], 후진 Out[601], 전진 완료 In[515], 복귀 완료 In[514]로 연결했다면:

1. IO Out 600 ON → IO Wait 515 ON
2. IO Out 600 OFF → IO Out 601 ON
3. IO Wait 514 ON → IO Out 601 OFF

OLP의 Out/In과 프로그램 패널, IO 테스트는 같은 IO 상태를 사용한다. 설비는 Output으로 제어하고 완료 신호는 Input으로 확인한다. 설비가 관리하는 완료 센서는 자동 갱신되며 수동 입력을 제한한다. IO 명령은 작업공간과 로봇 프로그램 파일에 저장된다.

## 저장과 충돌

설비 설정, 현재 위치, 파지 관계와 필름 형상을 `.inosim` 작업공간 저장·복구에 포함한다. 실행 중 위치 변화는 간격을 두어 자동 저장하며 불러온 설비를 자동 운전하지 않는다.

충돌 정지 모드에서는 가동부가 주변 장애물과 충돌하면 로컬 설비를 정지한다. 본체·로드 등 등록한 설비 부품 사이의 정상 접촉과 그리퍼 파지 접촉은 허용한다. 외부 컨트롤러 관측에는 로컬 설비 정지를 외부 컨트롤러 정지로 적용하지 않는다. 필름 접촉은 변형 시뮬레이션의 평면·바닥 제약으로 처리한다.
