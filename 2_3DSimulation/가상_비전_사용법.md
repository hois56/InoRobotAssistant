# 가상 비전 사용법

3D 시뮬레이션 하단 도크의 **비전** 버튼으로 가상 비전 패널을 엽니다. 가상 비전은 카메라 FOV 확인, 9점·회전 중심 캘리브레이션, 기준 위치 대비 보정값 계산과 로봇 통신을 실제 현장과 같은 순서로 실습하기 위한 기능입니다.

패널은 **카메라 → 캘리브레이션 → 작업물 → 통신** 네 탭으로 나뉩니다. 자주 쓰지 않는 값은 각 탭의 **고급 설정**에 접혀 있고, 선택한 통신 방식과 관계없는 항목은 표시되지 않습니다.

## 1. 카메라 모델과 FOV

1. 로봇을 배치한 뒤 **가상 비전 배치**를 누릅니다. 로봇이 도달할 수 있는 작업 영역 위에 카메라, 작업물 기준 위치, 캘리브레이션 중심을 자동으로 맞춥니다.
   **테스트 모델링**에서 **Vision module**을 추가하면 모듈의 **Camera** 부품에 상향 촬상이 자동으로 연결됩니다. 별도의 기본 카메라를 추가할 필요가 없으며 모듈이나 Camera 부품을 이동하면 비전 시점도 따라 움직입니다. 통신은 기존처럼 연결 버튼을 눌러 시작합니다.
2. 카메라는 모델 트리에 **VISION 1**(비전 카메라)로 등록됩니다. 위치와 회전은 모델 트리에서 입력하며 모델과 비전 시점이 함께 움직입니다. 카메라 탭에는 위치·회전 좌표를 표시하지 않습니다.
3. 직접 만든 모델이나 불러온 모델을 카메라로 쓰려면 모델 트리에서 우클릭 → **비전 카메라로 등록**을 누르거나, 카메라 탭에서 모델을 선택한 뒤 **선택한 모델로 등록**을 누릅니다. 모델 바닥 중앙에서 아래를 바라보도록 렌즈 위치가 정해지고, 기본 카메라 모델은 제거됩니다. 등록을 풀려면 같은 메뉴의 **비전 카메라 해제**를 사용합니다.
4. **해상도**와 **초점 거리**를 바꾸면 3D 화면의 절두체와 바닥의 FOV 영역이 즉시 바뀝니다. 화소 크기, 검출 노이즈, 처리 시간 등은 **고급 설정**에 있습니다.
5. 영상은 실제 모델 색상으로 항상 라이브 갱신됩니다. 영상 아래 **FOV 표시** 체크로 3D 화면의 FOV 영역을 켜거나 끕니다. 카메라 탭에는 FOV 크기, 분해능(mm/px), 작업 거리가 함께 표시됩니다.
6. 기준 위치를 등록한 뒤 카메라 탭의 **촬상**을 누르면 한 번 측정하여 기준 위치 대비 dX·dY·dθ 보정값을 확인합니다. 라이브 영상 갱신만으로 측정 횟수가 늘어나지는 않습니다.
7. 카메라 탭의 **촬상 방향**에서 **하향 (위 → 아래)** 또는 **상향 (아래 → 위)**을 선택합니다. 상향 촬상은 작업물 아랫면을 측정하며, 방향을 바꾸면 FOV 표시 높이를 촬상 방향에 맞추고 기존 캘리브레이션·기준 위치를 초기화합니다. 방향 변경 후 캘리브레이션과 기준 위치를 다시 등록하세요.

## 2. 캘리브레이션

- Tool에 오프셋을 두고 부착된 원형 마크를 3×3 격자 9점으로 이동하며 화소 ↔ 로봇 좌표(BASE) 변환을 구합니다.
- 같은 위치에서 Tool을 ± 회전 각도만큼 돌려 마크가 그리는 원의 중심을 찾고, 마크가 TCP 축에서 벗어난 만큼을 보정합니다(회전 중심 보정). 회전 점 수를 0으로 두면 이 보정 없이 절대 좌표가 마크 오프셋만큼 치우치는 것을 확인할 수 있습니다.
- 카메라를 기울이면 어파인 모델의 잔차가 커집니다. **고급 설정**의 변환 모델을 **호모그래피 (원근)** 로 바꿔 원근 오차가 사라지는 것을 비교하세요.
- 캘리브레이션 높이 Z는 작업물 윗면 높이와 같아야 합니다. 높이가 다르면 시차에 따른 위치 오차가 생깁니다.
- 각 점의 화소·로봇 좌표와 잔차는 **점별 결과**를 펼쳐 확인합니다.

캘리브레이션은 세 가지 방법으로 실행합니다.

| 방법 | 동작 |
| --- | --- |
| 자동 캘리브레이션 | 패널 버튼으로 시뮬레이션 로봇을 직접 이동하며 실행 |
| Socket (비전 주도) | 로봇이 `CALSTART`를 보내면 비전이 `n,X,Y,R`로 다음 위치를 알려 주고, 로봇은 이동 후 `CALPOS,X,Y,R`로 현재 위치를 보고 |
| IO·필드버스 (비전 주도) | CalStart/CalPoint 비트와 32비트 실수 워드로 같은 순서를 진행 |

## 3. 작업물, 기준 위치와 보정값

1. 직접 불러온 3D 모델을 쓰려면 **작업물 오브젝트**에서 해당 모델을 선택하고 **기준 위치 등록**을 누릅니다. 모델을 선택한 시점 또는 기준 위치를 등록한 시점의 위치·회전이 무작위 이동의 기준이 됩니다. **기본 형상 생성**을 선택하면 기존처럼 **기준 위치에 생성**으로 기본 작업물을 만들 수 있습니다. 로봇은 `MST,X,Y,R`로 기준 위치를 등록할 수 있습니다.
2. 회전 중심이 **로봇 픽업점**이면 작업물이 회전했을 때 픽업점이 따라 움직이도록 dX·dY를 계산합니다. 로봇은 `Offset(P_pick, (dX, dY, 0, dθ, 0, 0))`으로 그대로 보정합니다.
3. **무작위 생성**은 X·Y 각각 기본 ±50 mm, Rz 기본 ±180° 범위에서 위치·각도를 바꿉니다. 오브젝트를 선택했다면 새 모델을 만들지 않고 같은 모델을 이동하며 색상·형상·크기를 유지합니다. **기준 위치로 이동**으로 원래 기준 위치에 되돌릴 수 있습니다. 기본 형상 모드에서 만든 작업물은 흡착·그리퍼로 집을 수 있는 오브젝트로 자동 등록됩니다.
4. **고급 설정**의 **작업물을 가져가면 자동 공급**, **생성 신호 OUT**, **생성 후 자동 검사**로 공급기·PLC 없이 반복 사이클을 만들 수 있습니다.

## 4. 통신

**통신** 탭의 연결 대상은 **가상/실제 컨트롤러**로 고정됩니다. 프로토콜은 **Socket**, **Ethernet/IP** 중 선택하며, 두 프로토콜 모두 **비전 역할**을 서버 또는 클라이언트로 설정할 수 있습니다. 설정 후 **연결** 버튼을 누르면 한 번 연결을 시도합니다. 통신 설정을 바꾸거나 저장한 작업을 불러온 뒤에는 **연결**을 다시 누릅니다. 연결 중에는 같은 버튼이 **연결 해제**로 바뀝니다.

### 가상/실제 컨트롤러 (가상환경_시작.bat 로컬 서버)

가상 비전은 지정한 IP(기본 127.0.0.11)를 사용합니다. 서버 역할에서는 비전 포트로 접속을 기다리고, 클라이언트 역할에서는 대상 IP·포트로 연결합니다. 가상 컨트롤러 기준 설정은 다음과 같습니다.

| 프로토콜 | 비전 역할 | 주소 |
| --- | --- | --- |
| Ethernet/IP | 서버 (어댑터) 또는 클라이언트 (스캐너), 기본 44818 | Class 1 I/O, 구성 1·O→T 100·T→O 101, 256바이트. 비전이 클라이언트이면 로봇 InW[32] = O→T 0번 바이트 |
| Socket | 서버 또는 클라이언트, 기본 5000 | 문자열 명령·응답 |

- 한 컨트롤러의 입력 영역은 한 장치만 쓸 수 있으므로 통신 테스터와 같은 버스를 동시에 쓰지 마세요. 다른 장치가 입력을 사용 중이면 통신 상태에 안내가 표시됩니다.
- Ethernet/IP는 주기 I/O와 별도로 세션 유지 메시지를 보냅니다. 연결에 실패하거나 통신이 끊어지면 자동으로 재시도하지 않으며, **연결** 버튼으로 다시 시도합니다.
- 송수신 프레임은 **통신 로그**를 펼쳐 확인합니다.

### 데이터 영역 (표준 배치)

각 워드의 실제 InW/OutW 번호는 **주소 맵**을 펼치면 현재 설정 기준으로 표시됩니다.

| 워드 | 비전 → 로봇 (InW) | 로봇 → 비전 (OutW) |
| --- | --- | --- |
| +0 | 상태 비트: Ready, Busy, Done, OK, NG, 캘리브레이션 완료, 기준 등록, 오류, 캘리브레이션 중 | 제어 비트: Trigger, CalStart, CalPoint, Master, Reset |
| +1 | 결과 코드 (1 OK, 2 대상 없음, 3 한계 초과, 4 캘리브레이션 필요, 5 기준 없음, 9 오류) | 작업 번호 |
| +2~+7 | dX, dY, dθ (32비트) 또는 다음 캘리브레이션 X, Y, R | 로봇 현재 X, Y, R (32비트) |
| +8~+9 | 점수 또는 다음 캘리브레이션 번호 | – |
| +10~+11 | 결과 카운터 | – |

핸드셰이크: 로봇이 제어 비트를 켜면 비전이 Busy → Done(OK/NG)을 켜고, 로봇이 제어 비트를 끄면 Done이 꺼집니다. 패널·Socket·자동 검사는 값만 갱신하고 Done은 켜지 않습니다.

**값만 (X,Y,θ)** 배치와 32비트 정수 × 10000 형식은 프로젝트 생성기의 IO 비전 보정 라벨(`xwVision_offset_X/Y/A`, InW[54]·[56]·[58])과 호환됩니다(빠른 설정 `생성기 IO`).

## 5. 로봇 예제 프로그램

통신 탭 맨 아래의 **로봇 예제 프로그램**을 펼치면 현재 IP·포트·주소·형식으로 로봇 언어 예제가 만들어집니다. **복사**를 누르면 Windows 줄바꿈으로 클립보드에 복사되며, 자동 복사가 막힌 환경에서는 내용이 선택되므로 Ctrl+C로 복사합니다. P[200] 캘리브레이션 시작 위치, P[100] 기준 픽업 위치, P[101] 접근 위치를 먼저 티칭하세요.

| 방식 | 예제 |
| --- | --- |
| Socket 문자열 | 9점 + 회전 캘리브레이션, 기준 위치 등록, 검사 후 보정 픽업 (`Shot` → `dX,dY,dθ` → `Offset` 보정 이동) |
| IO 워드 (32비트) | 9점 + 회전 캘리브레이션, 검사 후 보정 픽업 (32비트 실수와 Trigger/Done 핸드셰이크) |
