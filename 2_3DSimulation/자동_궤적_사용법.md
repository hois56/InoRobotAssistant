# 곡선에서 위치값 만들기

3D 모델의 모서리·곡선을 따라 **X/Y/Z/A/B/C 위치 데이터**를 생성합니다. 결과는 **P.pts** 목록에 저장됩니다.

1. 사용할 로봇, Tool, Wobj를 선택하고 원하는 TCP 자세를 맞춥니다.
2. 하단 **P.pts → 곡선에서 위치 생성**을 누릅니다. 프로그램 패널의 **자동 궤적 생성** 아이콘으로도 열 수 있습니다.
3. **3D 화면의 모서리·곡선을 연결 순서대로 클릭**합니다. 마우스를 올리면 노란색, 선택하면 순서 번호가 표시됩니다. 같은 곡선을 다시 클릭하거나 목록의 ×를 누르면 해제됩니다. 모따기나 둥근 코너에 별도 모서리가 있으면 그 부분도 연결 순서에 포함합니다.
4. **포인트 간격**과 **시작 포인트 번호**를 입력합니다. 예를 들어 간격 `10 mm`, 시작 번호 `100`이면 `P[100]`, `P[101]` … 순서로 생성합니다. 각 구간의 간격은 최대 10 mm이며 꺾임점도 포함하므로 마지막 간격은 더 짧을 수 있습니다. 기존 번호와 겹치면 덮어쓰지 않고 알려줍니다.
5. **위치 미리보기**를 누릅니다. 3D 경로와 위치 개수, 번호 범위, 좌표 표를 확인합니다. 표는 앞 10개 위치를 보여줍니다.
6. **P.pts에 추가**를 누르면 전체 위치 목록이 열립니다. 값을 수정하거나 **P.pts 내보내기**로 저장합니다. 추가한 위치는 실행 취소할 수 있습니다.

위치 생성은 이동 명령을 추가하거나 로봇을 움직이지 않습니다. 위치로 이동하려면 P.pts에서 해당 행을 선택한 뒤 **위치로 이동**을 사용합니다. 이때 기존 이동 기능에서 도달 범위와 이동 경로를 검사합니다.

- X/Y/Z와 A/B/C는 선택한 **Wobj** 기준입니다. A/B/C는 각각 RZ/RY/RX입니다. 각 포인트의 자세는 현재 TCP 자세를 유지합니다.
- **고급 설정**에서 방향 반전, 시작·끝 잘라내기, BASE X/Y/Z 오프셋, 현재 TCP 로컬 자세에 대한 ΔRX/RY/RZ 보정(ZYX)을 설정할 수 있습니다.
- 간격 기준은 원래 꺾임점을 유지합니다. 현 높이 오차 기준은 가져온 폴리라인에 대한 허용 오차 이내로 포인트를 줄인 뒤 최대 간격을 적용합니다.
- 서로 떨어진 곡선은 연결 허용 거리 이내일 때만 연결됩니다. 기본값은 0.1 mm이며 한 번에 최대 2,000개 위치를 생성합니다.
- Arm 파라미터와 외부 축은 현재 로봇 값을 사용합니다. 위치 데이터 생성 자체는 도달 가능성이나 간섭을 보장하지 않습니다.

고정 뷰와 분리 뷰에서도 클릭할 수 있습니다. 회전·이동·줌은 유지되며 드래그는 곡선을 선택하지 않습니다. 가려진 모서리는 화면을 돌려 보이게 한 뒤 선택합니다. Esc 또는 ×로 닫습니다.

STEP/메시는 가져온 삼각화 경계, 스케치와 DXF는 표시용 곡선을 기준으로 합니다. 원·호도 이산 위치로 생성하며 CAD 원본의 해석적 곡면 정밀도나 곡면 법선에 따른 자동 자세 추종은 지원하지 않습니다.
