## CAD Lightweight

### Ver 1.2 (2026.10.30)

- `[추가]` 영점 좌표축을 모델의 면·직선 모서리에 평행 또는 수직으로 맞추고, X+/X−/Y+/Y−/Z+/Z− 방향을 지정할 수 있도록 했습니다.
- `[개선]` 여러 축의 맞춤 조건을 유지하면서 기준 방향·반대 방향을 즉시 적용하고, 고정된 맞춤을 확인하거나 해제할 수 있도록 했습니다.
- `[개선]` 영점·좌표계를 적용하면 선택한 위치가 새 0,0,0이 되며, 여러 번 적용한 변경도 STEP 저장에 반영되도록 했습니다. 면 스냅을 지원하고 대용량 모델의 일부 부품에서 스냅이 제한되던 문제를 해결했습니다.
- `[추가]` Ctrl+Z·Ctrl+Y로 부품 숨김·표시, 전체 포함·제외, 영점·좌표계 변경을 되돌리거나 다시 실행하고, Delete 키로 선택한 부품을 숨길 수 있도록 했습니다.
- `[추가]` 드래그 선택 버튼과 Alt+왼쪽 드래그로 사각형 선택을 지원합니다. 드래그 방향에 따라 완전히 포함된 부품 또는 일부가 걸친 부품을 선택할 수 있습니다.
- `[개선]` 숨긴 부품을 선택한 동안에는 3D 화면에 임시로 표시하고, 선택을 해제하면 다시 숨기도록 했습니다. 임시 표시는 STEP 내보내기 포함 상태를 바꾸지 않습니다.
- `[개선]` 그룹을 자동으로 펼치지 않고 선택 부품이 포함된 상위 그룹을 표시하며, 여러 항목을 선택한 뒤 한 번에 숨길 수 있도록 했습니다.
- `[수정]` STEP 가져오기와 부품 제외·원점·축 방향 변경 후 저장할 때 원본 부품·면 색상이 바뀌거나 누락되던 문제를 해결했습니다. 색상 정보가 없는 부품은 회색으로 표시합니다.
- `[수정]` STEP을 그대로 저장하거나 부품 제외·원점·축 방향 변경 후 저장할 때 파일 크기가 불필요하게 증가하던 문제를 해결했습니다.

### Ver 1.1 (2026.10.23)

- `[추가]` 하위 항목들을 그룹으로 묶어 관리할 수 있도록 그룹 만들기 기능을 추가했습니다.
- `[수정]` 다운로드한 ZIP 파일을 빈 압축파일로 인식하던 문제를 해결했습니다.

### Ver 1.0 (2026.07.25)

- `[신규]` 대용량 STEP/STP 파일을 PC에서 직접 불러와 부품별로 확인할 수 있는 경량 CAD 도구를 추가했습니다.
- `[추가]` 선택한 부품만 STEP 파일로 저장할 수 있도록 지원합니다.
- `[추가]` 파일의 영점 위치를 수정할 수 있습니다.
