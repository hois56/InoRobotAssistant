## InoRobot Label Gen

### Ver 2.1.0

- `[수정]` 동일한 주소에 Bit·Byte·Word 라벨이 함께 존재할 때 일부 라벨이 누락되거나 덮어써지던 문제를 수정했습니다.
- `[변경]` 주소 충돌 시 Bit 라벨을 우선 표시하고, 관련 Byte·Word 라벨은 설명 영역에 함께 표시하도록 변경했습니다.
- `[추가]` 설명에 포함된 `Double Word`, `2 Word`, `DWORD`, `32-bit` 표기를 자동으로 인식하는 기능을 추가했습니다.
- `[수정]` Double Word 데이터가 Excel에서 32-bit 범위로 올바르게 병합되도록 수정했습니다.
- `[변경]` 프로그램 제목과 실행 파일의 버전 정보를 V2.1로 통일했습니다.

### Ver 2.0.0

- `[신규]` 개별 버전으로 제공되던 라벨 포맷을 하나의 프로그램으로 통합했습니다.
- `[추가]` `20글자 Word / 20글자 Byte / 64글자 Word / 64글자 Byte` 포맷 선택 기능을 추가했습니다.
- `[추가]` Excel → JSN과 JSN → Excel 화면에서 각각 포맷을 선택할 수 있도록 했습니다.
- `[신규]` JSN 데이터를 Excel로 변환하기 전에 라벨명과 설명을 확인·수정할 수 있는 편집 화면을 추가했습니다.
- `[추가]` 선택한 포맷에 맞춰 생성되는 Excel 파일명을 자동으로 지정하는 기능을 추가했습니다.
- `[변경]` 20글자 포맷에서는 긴 변수명을 자동으로 축약하도록 변수명 표준화 기능을 개선했습니다.
- `[변경]` 현재 선택된 포맷과 불러온 데이터 개수가 상태 영역에 표시되도록 변경했습니다.
- `[변경]` 기본 포맷을 `20글자 Word`로 변경했습니다.
