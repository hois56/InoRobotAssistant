Zero Calibration Tool

툴 설명

로봇의 영점이 엔코더 베터리 방전 혹은 영점값 데이터 소실 등 하드웨어 고장 및 교체가 아닌 경우 엔코더 영점을 하드웨어 보정 툴없이 보정하는 툴입니다.

사용 방법 :

  1. 로봇의 공장 출하 영점 값을 아래 '공장 출하 영점값' 항목에 입력합니다. (출하값은 출고 시 부착된 종이에 적혀있거나, 로봇의 파라미터에서 확인 가능합니다.)
  2. 로봇을 JOG로 동작시켜 영점(바디의 홈)에 최대한 근접하게 맞춥니다.
  3. 각 축의 티칭값을 입력합니다. (Zero 파라미터에 현재 값 읽기를 클릭하여 현재 로봇의 위치 값을 엔코더 값으로 읽을 수 있습니다.)
  4. 현재 위치의 엔코더 값을 '티칭값' 항목에 입력합니다.
  5. '최종 결과' 항목에 계산된 값을 확인합니다.
  6. 로봇 Zero 파라미터에 계산된 값을 입력합니다.
