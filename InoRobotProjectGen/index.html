Program Operation Guide

1 프로그램 시작

상위 제어기(PLC)에서 로봇 프로그램을 시작하는 신호 순서입니다.

xRobot_run (IN[512])
PLC→Robot
xRobot_ready (OUT[512])
Robot→PLC
xRobot_busy (OUT[513])
Robot→PLC

2 프로그램 정지

프로그램 정지 신호를 수신하면 로봇은 현재 동작을 완료 후 대기 상태로 전환됩니다.

xRobot_run (IN[512])
PLC→Robot
xRobot_busy (OUT[513])
Robot→PLC
xRobot_ready (OUT[512])
Robot→PLC

3 알람

로봇 이상 발생 시 알람 신호를 출력합니다. 알람 리셋 신호 수신 후 해제됩니다.

xRobot_alarm (OUT[514])
Robot→PLC
xAlarm_reset (IN[515])
PLC→Robot

4 로봇 호밍

호밍 신호 수신 시 로봇이 홈 위치로 복귀합니다. 복귀 완료 후 호밍 완료 신호를 출력합니다.

xRobot_homing (IN[516])
PLC→Robot
xRobot_homing_comp (OUT[516])
Robot→PLC

5 Wait Pos

각 프로세스의 대기 위치 이동 신호입니다. Pn = 프로세스 번호.

xPn_wait_pos_start (INW[n])
PLC→Robot
xPn_wait_pos_comp (OUTW[n])
Robot→PLC

6 Work Pos

작업 동작 시작 신호입니다. 작업 완료 후 완료 신호를 출력합니다.

xPn_work_start (INW[n])
PLC→Robot
xPn_work_comp (OUTW[n])
Robot→PLC

7 Teaching Mode

티칭 모드 진입 시 로봇이 안전 속도로 전환됩니다. 티칭 완료 후 신호를 해제합니다.

xTeaching_mode (IN[520])
PLC→Robot
xTeaching_mode_on (OUT[520])
Robot→PLC

8 Tool Control

툴(그리퍼 등) 동작 명령 및 완료 신호입니다. 툴 번호(n)에 따라 주소가 결정됩니다.

xTool_n_on (INW[n])
PLC→Robot
xTool_n_comp (OUTW[n])
Robot→PLC

프로세스 타입 설명

프로젝트 생성 시 선택하는 각 프로세스 타입의 역할과 특징을 설명합니다.

Tray 트레이 공정

격자형으로 배열된 트레이에서 순차적으로 픽앤플레이스하는 공정입니다. 행/열 수와 피치를 설정하면 자동으로 각 셀 좌표를 계산하여 동작합니다. 트레이 교체 신호와 완료 신호를 통해 PLC와 연동합니다.

Stage 스테이지 공정

고정된 위치(스테이지)에 대해 단순 픽앤플레이스 또는 조립 동작을 수행하는 공정입니다. 단일 위치 작업에 최적화되어 있으며, 센서 신호와 연동하여 부품 유무를 확인합니다.

Vision Calibration 비전 캘리브레이션

카메라 비전 시스템과 연동하여 로봇 좌표계를 보정하는 공정입니다. 캘리브레이션 완료 후 보정값을 적용하여 이후 비전 기반 공정의 정밀도를 향상시킵니다.

IO COMM IO 통신 공정

PLC IO 신호를 통해 동작하는 공정입니다. 상위 제어기의 신호에 따라 로봇이 반응하며, Communication IO 방식의 핸드셰이킹으로 동작합니다.
